Given a formal power series $F(x)$ where

$$ F(x) = \sum_{i=0}^{\infty}{\alpha_i(x - \beta)^i} $$

for a constant $\beta$. Assume $F(\beta)=0$ and $\alpha_1=F'(\beta)$ is a unit, and set $Q_0=\beta$. A formal-series root can be found iteratively: if $F(Q_k)=0\pmod{x^{2^k}}$, then

since $F^\prime(Q_k)$ remains a unit modulo $x^{2^k}$,

$$ Q_{k+1} = Q_k - \frac{F(Q_k)}{F^\prime(Q_k)} \pmod {x^{2^{k+1}}}. $$
