# Gaussian_gcd

- Template: `codebook/6_Math/Gaussian_gcd.cpp`
- Harness: `harness.cpp`
- Oracle: enumerate Gaussian divisors in a larger box, check exact divisibility, and compare maximal norm; associates are intentionally accepted.
- Domain tested: `a,b` in the Gaussian box `[-8,8]^2`, with `b != 0`.
- Actual problem: [AtCoder ABC444 G](https://atcoder.jp/contests/abc444/tasks/abc444_g), a current contest problem whose editorial uses Gaussian integers.
