# floor_enumeration

- Template: `codebook/6_Math/floor_enumeration.cpp`
- Harness: `harness.cpp`
- Oracle: direct scan of every `i` and maximal contiguous interval with equal `n/i`.
- Domain tested: every `1 <= n <= 10000`.
- Actual problem: [Luogu P2261](https://www.luogu.com.cn/problem/P2261), a standard number-theoretic block / quotient-interval application.
