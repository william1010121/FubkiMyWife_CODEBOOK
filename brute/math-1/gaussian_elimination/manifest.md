# Gaussian_Eliminatin

- Template: `codebook/6_Math/Gaussian_Eliminatin.cpp`
- Harness: `harness.cpp`
- Oracle: exact Cramer's-rule determinants for independently generated nonsingular integer systems; compare the full reduced identity and solution columns.
- Domain tested: 2500 systems, dimensions `1..5`, entries in `[-3,3]`, nonzero determinant.
- Actual problem: [Luogu P3389](https://www.luogu.com.cn/problem/P3389), Gaussian elimination template problem.
