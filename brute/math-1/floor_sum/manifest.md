# floor_sum

- Template: `codebook/6_Math/floor_sum.cpp`
- Harness: `harness.cpp`
- Oracle: direct sum of `floor((a*i+b)/m)` for every `i`.
- Domain tested: `0 <= n <= 60`, `1 <= m <= 50`, `0 <= a,b <= 100`.
- Actual problem: [AtCoder Library Practice Contest S](https://atcoder.jp/contests/practice2/tasks/practice2_s), the canonical floor-sum problem.
